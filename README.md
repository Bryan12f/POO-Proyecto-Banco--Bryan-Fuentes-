### Instrucciones para Compilar y Ejecutar en NetBeans
1. **Clonar o descargar** este repositorio en tu computadora.
2. Abrir **Apache NetBeans**.
3. Ir a `File -> Open Project` y seleccionar la carpeta del proyecto (`CuentaBancaria`).
4. Si el IDE presenta bloqueos de permisos con Windows Defender, se recomienda mover la carpeta directamente a la raíz del disco duro (ej. `C:\Java\CuentaBancaria`).
5. Hacer clic derecho sobre el proyecto y seleccionar **"Clean and Build"** para limpiar y compilar los archivos fuentes de forma limpia.
6. Localizar el archivo `Main.java` dentro del paquete `com.mycompany.cuentabancaria`.
7. Hacer clic derecho sobre `Main.java` y seleccionar **"Run File"** (o presionar `Shift + F6`) para ejecutar la simulación de pruebas.
